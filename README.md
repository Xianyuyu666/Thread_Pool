# Thread_Pool
## 项目介绍
这是一个基于C++11实现的线程池，支持提交任务，多线程同时执行多个任务，支持任意返回值，任意参数的任务
## 技术栈
C++11新特性
## 核心原理
提交任务->入队->唤醒线程->取任务->执行并返回future
## 关键实现
### 成员变量
1.vector<std::thread> workers_:线程池，存放工作线程
2.queue<std::function<void()>> tasks_:任务队列，存放函数
3.mutex queue_mutex_:互斥锁，防止多线程同时读写线程池变量
4.bool stop_:标记线程池是否停止
5.condition_variable condition_:解决线程虚假唤醒后取空队列问题
### 构造函数实现
根据传入的参数创建对应数量的线程放入vector线程池,每个线程在while(true)不断重复以下逻辑:1.加锁 2.调用条件变量.wait(lock,predicate),如果收到停止信号或者队列不为空，线程醒来尝试获得锁 3.如果收到停止信号同时队列为空则break退出循环，否则取出任务 4.先释放锁然后执行任务函数
### 析构函数实现
1.加锁 2.修改stop_ = true 3.唤醒所有线程 4.释放锁 5.循环遍历线程池join等待所有线程结束
